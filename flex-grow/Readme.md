##Flex Grow:
A visually engaging football website showcasing some of the greatest football legends, their career journeys, achievements, and memorable clubs.

## 🌐 Live Demo

🔗 [View SoccerSphere](https://webdev-flex-grow.vercel.app/)

## ✨ Features

* ⚽ Profiles of legendary football players
* 🏆 Career journeys and club histories
* 🎨 Clean and attractive user interface
* 📱 Responsive layout (if implemented)
* 💻 Simple and beginner-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* `flex-grow` property

## 🐐 Featured Football Legends

* Cristiano Ronaldo
* Lionel Messi
* Paolo Maldini
* Zlatan Ibrahimović
* Roberto Carlos

## 📚 What I Learned

* Understanding CSS Flexbox
* Using the `flex-grow` property
* Creating layouts with flexible elements
* Improving HTML and CSS skills
* Building a frontend project

## 🚀 Getting Started

Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd flex-grow
```

Open `index.html` in your browser to view the project.
