# ☕ Cafe Brew – Coffee Shop Website

A modern and visually appealing coffee shop website built using HTML and CSS. Cafe Brew showcases a coffee menu, an engaging landing page, an about section, and contact information with a clean and attractive layout.

## 🌐 Live Demo

🔗 [View Cafe Brew Website](https://webdev-rho-five.vercel.app/)

## ✨ Features

* ☕ Attractive coffee shop landing page
* 🧋 Coffee menu with product images and prices
* 📖 About Us section
* 📍 Contact section with cafe location and details
* 📱 Responsive design for different screen sizes
* 🎨 Clean UI with a warm coffee-inspired color palette
* 🔗 Navigation links for different website sections
* 📩 Contact form UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* Media Queries
* Font Awesome

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Cafe-Brew
```

### 3. Run the project

Open `index.html` in your preferred web browser.
